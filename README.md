# Estudio Fotográfico — Gestión de Inventario (Neo4j Cloud)

Aplicación web en **Streamlit** conectada a una base de datos orientada a grafos en **Neo4j AuraDB**.
Permite administrar el inventario (cámaras, lentes, mochilas e impresiones), consultar compatibilidades mediante recorridos de grafo (*traversals*) y gestionar paquetes fotográficos.
